## 目标

新建 `muskitty-cascade` crate，实现 CSS Cascade Level 5 的核心算法：
从 DOM 树 + 多源 CSSStyleSheet 列表 → 每元素每属性的 computed value。

**输出边界**: computed value（§4.4）。Used/Actual value 推迟到 Phase 3/4。

## 设计

### 数据流

```
DOM 树 + CssStyleSheet[] (带 origin 元数据)
    │
    ▼  §5 Filtering
DeclaredValue[] (每元素每属性，无序)
    │
    ▼  §6.1 Cascade 排序
DeclaredValue[] (有序，按 7 准则降序)
    │
    ▼  取首项 → §4.2 Cascaded Value
    │
    ▼  §4.3 + §7 Defaulting (initial/inherit/unset)
SpecifiedValue
    │
    ▼  §4.4 Computed Value (相对单位解析、var() 求值)
ComputedValue
```

### 核心数据结构

```rust
/// §6.2: Cascade origin。
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub enum Origin {
    UserAgent,  // UA 默认样式
    User,       // 用户样式
    Author,     // 作者样式
}

/// §4.1: A declared value（cascade 输入项）。
pub struct DeclaredValue {
    pub property: String,
    pub value: Vec<ComponentValue>,
    pub important: bool,
    pub origin: Origin,
    pub specificity: Specificity,
    pub order: usize,  // §6.1 准则 7: 文档序
    pub from_style_attr: bool,  // §6.1 准则 4
}

/// §4.4: Computed value（cascade 输出）。
pub enum ComputedValue {
    /// 已解析为绝对值（如 "10px" → Length { value: 10.0, unit: "px" }）
    Resolved(Vec<ComponentValue>),
    /// 关键字（initial/inherit/unset 已在 defaulting 阶段处理）
    Keyword(String),
    /// 未识别的属性值（原样保留）
    Raw(Vec<ComponentValue>),
}

/// 每元素的 computed style 表。
pub struct ComputedStyle {
    pub properties: HashMap<String, ComputedValue>,
}
```

### Property Registry

```rust
/// 属性元数据（硬编码常用属性，后续可扩展）。
pub struct PropertyDefinition {
    pub name: &'static str,
    pub initial_value: &'static str,
    pub inherited: bool,
    pub percentages: PercentageBasis,  // 参考值类型

```

width/height/border/background/position/visibility/line-height/z-index/
overflow/text-align/white-space/box-sizing/opacity/cursor。
